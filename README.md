# Eximius Kreativ Solutions Portfolio

A responsive, single-page portfolio for Eximius Kreativ Solutions.

## Preview locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Before publishing
- Replace `234XXXXXXXXXX` in the WhatsApp links with the business number.
- Confirm the featured-work visuals and service descriptions match approved client work.
- Add original high-resolution project artwork to the work gallery as it becomes available.

The page uses plain HTML, CSS and JavaScript, with scroll-reveal animation and an auto-advancing client-review carousel. No build step is required.
